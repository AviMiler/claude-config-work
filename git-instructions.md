# Git Instructions

The user does all git work: commit, push, PR and merge.

## Rules

- Work on the current branch. Do not switch or create branches unless the user asks.
- The agent never commits, pushes, opens a PR or merges.
- Never force-push.
- Never auto-resolve merge conflicts. Report them to the user.
- Dangerous git commands are set to `ask` in `settings.json`.
